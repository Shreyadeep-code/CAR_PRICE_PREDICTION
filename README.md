# Car Price Prediction

A machine learning project for predicting used car prices from historical vehicle data.

## Features

* Data cleaning and preprocessing
* Feature engineering
* Categorical feature encoding
* Regression model training and evaluation
* Car price prediction

## Data Preparation

Missing values and duplicates are handled, irrelevant columns are removed, and data types are corrected.

A `Car_Age` feature is created from the manufacturing year. Categorical features such as fuel type, seller type, and transmission are encoded before training.

## Models

The project compares regression models such as:

* Linear Regression
* Random Forest Regressor

Models are evaluated using **R² Score**.



## Goal

To build a reliable model for estimating the selling price of used cars.
